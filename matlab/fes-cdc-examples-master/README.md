# fes-cdc-examples


This repository contains the code for the numerical examples in the paper "Sampled-Data Online Feedback Equilibrium Seeking: Stability and Tracking" by Giuseppe Belgioioso, Dominic Liao-McPherson, Mathias Hudoba de Badyn, Saverio Bolognani, Florian Dörfler, and John Lygeros.

# Building automation

You must first install the [BRCM Toolbox](https://control.ee.ethz.ch/software/BRCM-Toolbox.html) and have it included in your MATLAB path. You may install the BRCM toolbox via [tbxmanager](https://www.tbxmanager.com/).

To run the building automation example, run `script_buildings.m` inside the `buildings` folder. You may modify the occupancy model inside `script_people.m`. 

# Robotic coordination game

To run the robotic coordination example, run `main.m` inside the `game` folder.
